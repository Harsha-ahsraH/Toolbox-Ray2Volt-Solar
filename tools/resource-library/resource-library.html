Adding a resource

Everything on this page comes from one file: tools/resource-library/resource-library-catalogue.js. Add an entry there and it appears here.

There are two kinds of entry, and the difference is not cosmetic:

  • In toolbox — the file is committed into this repository. One-click download and it works offline. The repository is public: anyone on the internet can download the file directly by its address, the tool password does not protect it, and it stays in the history even after you delete it. Use this only for material you would be happy for a competitor or a customer to read.
  • Drive link — the file stays in Drive and this is only a link. Whoever owns that folder decides who can open it, and the team can add files without needing repository access. Use this for anything internal: price lists with margins, vendor contracts, signed documents, templates holding real figures.

If you are not sure which to use, use a Drive link.
