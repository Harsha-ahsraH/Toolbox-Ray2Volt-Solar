# Preserve browser tools with local agent execution

To expose every Tool Operation to AI agents on six Windows 11 workstations without regressing the existing browser toolbox, keep the browser tools as a supported interface and add a shared local Ray2Volt CLI. The first release may drive the existing pages through browser automation to preserve output compatibility, while reusable business and calculation logic moves incrementally into shared modules consumed by both interfaces; this was chosen over a disruptive rewrite or permanent DOM-only automation.
