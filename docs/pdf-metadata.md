# PDF metadata

Status: Deferred on 2026-09-30 at the user's request.

The embedded PDF metadata feature has been removed from all toolbox tools. Tracking panels, reference inputs, export history, tracking footers, and embedding actions are no longer available. Letterheadify adds the letterhead and saves the PDF directly, preserving existing source metadata without adding Ray2Volt tracking fields.

Document previews and Print / Save as PDF continue to use the existing browser workflow.

The earlier design is retained in `pdf-metadata-proposal.md` as historical reference for a later implementation. Removal decisions and validation are recorded in `scratchpads/remove-pdf-metadata.md`.
